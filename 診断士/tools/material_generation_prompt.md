# 教材JSON生成プロンプト

あなたは中小企業診断士二次試験の作問者です。以下の条件で、実在企業や実在過去問を使わないオリジナル教材JSONを1件だけ作成してください。

## 条件

- 事例は `事例I`、`事例II`、`事例III` のいずれか
- 本文は原則3,500字前後。目安は3,400字から3,700字。短くても3,200字以上にする
- 本番に近く、ターゲット、課題、強み、弱みを直接書きすぎない
- 一文の中に強みと制約、機会と脅威が混ざる箇所を入れる
- ミスリードになるが完全な無関係ではない情報を少し入れる
- 設問は4問から5問
- 各設問に、答案例、解説、重要カードを入れる
- 分類対象 `parts` は25件から35件
- `parts` の `tag` は次から選ぶ
  - 強み
  - 弱み/課題
  - 機会
  - 脅威
  - 制約
  - 方向性
  - 設問根拠

## JSON形式

```json
{
  "id": "jirei3_001",
  "year": "R08想定",
  "caseName": "事例III",
  "title": "C社 ○○業 長文与件",
  "difficulty": "過去問レベルを意識したオリジナル長文。実在過去問ではない。",
  "passage": "本文",
  "parts": [
    {
      "tag": "強み",
      "text": "本文から抜き出す重要表現",
      "explanation": "なぜその分類になるか"
    }
  ],
  "story": {
    "current": "現在の状態",
    "change": "環境変化",
    "obstacle": "阻害要因",
    "goal": "目指す姿",
    "action": "取るべき施策",
    "effect": "期待効果"
  },
  "questions": [
    {
      "id": "q1",
      "question": "設問文",
      "limit": 100,
      "yokenCategory": "強み",
      "keywords": ["重要語1", "重要語2"],
      "modelAnswer": "答案例",
      "explanation": "解説",
      "cards": ["答案に使うカード"]
    }
  ]
}
```

## 出力ルール

- JSONだけを出力する
- Markdownのコードフェンスは付けない
- コメントは入れない
- JSONとしてパース可能にする
- 本文中の重要表現と `parts.text` は完全一致またはほぼ一致させる
